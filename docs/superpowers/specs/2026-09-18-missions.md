# Subway IRL — Missions, daily challenge and progression

**Date:** 2026-09-18
**Status:** Next phase after the settings/workout screens, approved by the user ("keep going with
other things while I'm away").
**Extends:** `2026-09-16-subway-irl-design.md` §5 and §7.

## Why

Right now every run has exactly one goal: a bigger number. Subway Surfers keeps you coming back
with three rotating missions, a daily reward and things to spend coins on. For a game meant to be
exercise, that matters more than usual: the missions are what turn "I'll do one run" into a
workout, and they should pull toward *movement*, not just score.

## Missions

Three active at a time, drawn from a seeded pool, shown on the menu and on the summary card.
A completed mission is replaced by a new one from the next tier, so they get slightly harder.

**Movement missions (the point of the game)** — jog N steps in one run; keep jogging for N seconds
without stopping; hit a fast-jog (Josh) streak of N seconds; do N jumps, N rolls, N lane changes;
finish a run without a single stumble.

**Run missions** — reach N m; score N; collect N coins in one run; N coins in a single magnet;
ride the hoverboard for N seconds; survive N near-misses with the TT.

**Habit missions** — play on two different days; three runs in one session; a run longer than your
last one.

Rules: never show two missions the player cannot make progress on in the same run; never show a
mission a small-room player physically cannot do (mode-aware pool); progress is visible live in the
HUD only when it changes (a small toast), never as permanent clutter.

## Daily challenge

One per local day, seeded from the date so it is the same all day: a fixed seed, a named goal
("Bandra to Andheri: 1200 m without getting caught"), and a single retry-friendly loop. Completing
it sets a flame on the menu and feeds the workout streak. Missing a day never punishes beyond
losing the streak.

## Coins and unlocks

Coins are already collected and totalled but buy nothing. Spend them on:
- **Characters:** 2–3 more procedural runners (different palettes/props in the existing rig — e.g.
  a college kid with a sling bag, a vada-pav seller, a kid in a cricket kit). No new art pipeline.
- **Hoverboard skins:** the flying carpet exists; add 2–3 recolours/variants.
- **A head start** (start 200 m in) and a **coin magnet boost** as consumables.

Prices are meaningful but not grindy: a first unlock should be reachable in a handful of runs.
Everything is cosmetic or mild; nothing sells power that breaks the catch rules.

## Progression

A simple level from lifetime score, shown on the menu with a bar. Levels award coins only — no
gating of content behind level, so a returning player is never blocked.

## Data

Extends `subway-irl.profile.v1` (see the settings/workout spec, which is landing first):
`missions` (the three active, their progress, the tier), `daily` (date, state), `wallet` (coins
spent/earned), `unlocks` (owned ids, equipped ids), `level`. Corrupt or missing data resets that
section only, never the whole profile, and never destroys coins already earned.

## Architecture

```
src/game/missions.ts     PURE: mission definitions, progress from RunStats + live counters, tiering
src/app/progression.ts   PURE: wallet, unlocks, level, daily challenge state; persistence
src/ui/missionCard.ts    The menu/summary mission list (+ css)
src/ui/shop.ts           The unlock screen (+ css)
```

`src/game` stays authoritative and deterministic: missions read the stats the sim already produces
and must never influence the simulation.

## Testing

- Unit: each mission's progress rule against synthetic `RunStats`/events; tiering and replacement;
  the mode-aware pool; daily seeding (same date → same challenge, next day → different); wallet
  arithmetic (never negative, never loses coins on corrupt data); level curve.
- Integration: a full simulated run updates missions and the wallet exactly once.
- Visual: `shoot` the mission list (in progress, one complete), the shop (afford / can't afford /
  owned / equipped) and the menu with the daily challenge. Open every PNG.
