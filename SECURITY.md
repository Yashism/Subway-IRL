# Security policy

Subway IRL runs entirely in your browser. It has no server, no accounts and no analytics, and your camera video never
leaves your device. Settings, progress and run history are stored in your browser's `localStorage`.

## Reporting a vulnerability

Please report anything that could expose a player's camera, data or device privately, using GitHub's
[private vulnerability reporting](https://github.com/Yashism/Subway-IRL/security/advisories/new), rather than a public
issue. We will acknowledge it as soon as we can and credit you in the fix if you wish.

## Supported versions

Only the latest `main` (and the hosted build deployed from it) is supported.
